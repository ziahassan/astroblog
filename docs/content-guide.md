# Content Guide

How to create content for the site. Each section includes the file location, required frontmatter, and a Templater template you can drop into Obsidian.

---

## Site map

| What you write | Folder | URL |
|---|---|---|
| Atomic notes / Zettelkasten | `src/content/notes/` | `/notes/slug` |
| Long-form essays | `src/content/essays/` | `/essays/slug` |
| Reading highlights (Readwise) | `src/content/reading/` | `/reading/slug` |
| Research articles | `src/content/articles/` | `/articles/slug` |
| Podcast / media appearances | `src/content/guestAppearances/` | `/media` |
| Teaching presentations | `src/content/teaching/` | `/teaching` |
| Music releases | `src/content/music/` | listed on home |

## Atomic Note

The core content type. These live in `src/content/notes/` and are the backbone of the graph. Filename becomes the slug and is used for `[[wiki-links]]` between notes.

**File naming:** Use the note title as the filename. Spaces are fine — Astro slugifies automatically.
`A great idea I had.md`

**Templater template:**
```
---
title: <% tp.file.title %>
tags: []
created: <% tp.date.now("YYYY-MM-DD") %>
---

<% tp.file.cursor() %>
```

**Optional fields:**
```yaml
tags: ["education", "AI"]
publishDate: 2025-06-01   # shows on the note page header
status: seedling           # or: growing, evergreen
```

**Wiki-linking:** Use `[[Note Title]]` or `[[slug]]` anywhere in the body. The site resolves both and builds the graph automatically.

## Essay

Long-form, polished writing. Lives in `src/content/essays/`. Shows up at `/essays`.

**File naming:** Use a short slug.
`on-learning-by-doing.md`

**Templater template:**
```
---
title: "<% tp.file.title %>"
publishDate: <% tp.date.now("YYYY-MM-DD") %>
description: ""
tags: []
draft: true
---

<% tp.file.cursor() %>
```

**Fields:**
| Field | Required | Notes |
|---|---|---|
| `title` | yes | Displayed as page H1 |
| `publishDate` | yes | Date object — `YYYY-MM-DD` |
| `description` | no | Shown in essay index card |
| `tags` | no | Used for tag pages at `/essays/tags/[tag]` |
| `draft` | no | `true` hides from index, still builds |
| `heroImage` | no | Path under `/public/images/essays/` e.g. `"/images/essays/cover.jpg"` |

## Reading Note

Mainly auto-imported from Readwise, but you can create them manually. Lives in `src/content/reading/`.

**File naming:** Usually auto-generated by Readwise. For manual entries, use a short title slug.

**Templater template:**
```
---
title: "<% tp.file.title %>"
author: ""
source: "manual"
tags: []
readDate: <% tp.date.now("YYYY-MM-DD") %>
---

## Notes

<% tp.file.cursor() %>

## Highlights
```

**Fields:**
| Field | Required | Notes |
|---|---|---|
| `title` | yes | Book / article title |
| `author` | no | Can be null |
| `source` | no | `"reader"` for Readwise, `"manual"` otherwise |
| `readDate` | no | `"YYYY-MM-DD"` as a string |
| `rating` | no | Number 1–5 |
| `url` | no | Source URL |

## Research Article

Formal research pieces, often exported from Quarto. Lives in `src/content/articles/`. Shows at `/articles`.

**File naming:** Short descriptive slug.
`ai-feedback-loops-2025.md`

**Templater template:**
```
---
title: "<% tp.file.title %>"
publishDate: <% tp.date.now("YYYY-MM-DD") %>
description: ""
tags: []
draft: true
abstract: ""
authors: ["Zia Hassan"]
---

<% tp.file.cursor() %>
```

**Fields:**
| Field | Required | Notes |
|---|---|---|
| `title` | yes | |
| `publishDate` | yes | |
| `description` | no | Short summary |
| `abstract` | no | Full abstract |
| `authors` | no | Array of strings |
| `doi` | no | e.g. `"10.1000/xyz123"` |
| `quartoFile` | no | Path to HTML in `/public/articles/` if Quarto export |
| `draft` | no | Hides from index |

## Guest Appearance / Podcast

Media appearances. Lives in `src/content/guestAppearances/`. All appear on the `/media` page.

**File naming:** Short slug.
`future-of-learning-podcast.md`

**Templater template:**
```
---
title: "<% tp.file.title %>"
podcast: ""
publishDate: <% tp.date.now("YYYY-MM-DD") %>
description: ""
url: ""
thumbnail: ""
duration: ""
---
```

**Fields:**
| Field | Required | Notes |
|---|---|---|
| `title` | yes | Episode title |
| `podcast` | yes | Show name |
| `publishDate` | yes | Air date |
| `url` | yes | Link to episode |
| `description` | no | |
| `thumbnail` | no | Image URL |
| `duration` | no | e.g. `"42:15"` |

## Obsidian vault setup

To use this as an Obsidian vault pointed at the repo:

1. Open Obsidian → **Open folder as vault** → point it at the repo root (`astroblog/`)
2. In Templater settings, set **Template folder** to a folder like `_templates/` in the vault
3. Set **Trigger on new file creation** so templates apply automatically by folder

**Suggested folder → template mapping in Templater:**

| Folder | Template |
|---|---|
| `src/content/notes` | `_templates/note.md` |
| `src/content/essays` | `_templates/essay.md` |
| `src/content/articles` | `_templates/article.md` |
| `src/content/guestAppearances` | `_templates/appearance.md` |

**To sync after writing:** the site rebuilds on push. Just commit and push from the repo — or set up the Obsidian Git plugin to auto-commit on a schedule.
