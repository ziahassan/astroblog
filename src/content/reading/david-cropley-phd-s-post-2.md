- Category: #articles
- Summary:: David Cropley, PhD believes that AI cannot be truly creative because it lacks the ability to define problems and validate solutions, which require human intent. While AI can assist in the creative process, the true creativity still comes from the human user. Therefore, using AI tools for art is similar to using a camera; the creativity remains with the person using the technology.
